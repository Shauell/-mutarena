# MUTARENA 4.0

Pacote oficial de publicação do jogo MUTARENA.

A branch `lua` guarda o pacote de lançamento e o workflow manual. Ao executar **Preparar site MUTARENA**, o GitHub cria a branch `gh-pages` com os arquivos reais do jogo.

Depois, configure o GitHub Pages para publicar a branch `gh-pages` na pasta `/ (root)`.
